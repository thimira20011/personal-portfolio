# Portfolio images

`pixel-workspace.webp` is an original illustration generated with the built-in image-generation tool for the owner's selected pixel developer workspace concept on 2026-11-08. It is decorative artwork, not a photograph of the owner's real desk. The transparent 1536 × 1024 source was resized to 960 × 640 and encoded as WebP at quality 0.88 (86,538 bytes). Alpha is preserved. Its exact generation prompt and timestamp are recorded in `pixel-workspace.webp.json`; the artwork's motion is implemented separately in `src/components/PixelWorkspace.js` and `src/lively.css`.

`nearu-live.jpg` is a 1440 × 900 capture of the public landing page at https://nearusab.me, taken on 2026-11-08 and saved as a compressed JPEG. It replaces the unrelated media browser image previously assigned to NearU, following the owner's instruction to use the live demo.

The portrait and remaining screenshots are cached copies of the images already supplied in `src/data/portfolio.js`, sourced from the owner's `thimira20011/portfolio-pictures` GitHub repository. No stock photographs, invented application UI, or generated portraits are used.

The original project assignments are preserved: `project-2.png` is GridWalk AI; `project-3.png` is the cloud project; `project-4.jpeg` is ShadowSense; `project-5.png` is GreenOps; `project-6.png` is ReuseHub; `project-7.png` is the game; `project-8.png` is the expense tracker. The ShadowSense image is low resolution and should be replaced with a higher-resolution original when one is available.
